# UnityLedger — Decentralized Voting System

A secure, transparent voting system built on the Ethereum blockchain. Voting records are tamper-proof and publicly verifiable. Access roles (Admin vs Voter) are determined automatically by your connected MetaMask wallet — no passwords or login accounts required.

---

## How Access Works

This system uses your **Ethereum private key** (via MetaMask) to identify who you are. There is no separate login page or database of usernames and passwords.

| Role | Who | What they can do |
|------|-----|-----------------|
| **Admin** | The wallet that **deployed** the smart contract | Add candidates, set voting dates, view results |
| **Voter** | Any other connected wallet | Cast a vote, view candidates and results |

When you connect your wallet, the app compares your address against the `admin` address stored in the smart contract. If they match, the admin panel is shown. Otherwise, you see the voter interface.

## Requirements

- [Node.js](https://nodejs.org/) v18.14.0
- [Truffle](https://trufflesuite.com/) (installed globally)
- [Ganache](https://trufflesuite.com/ganache/) (local blockchain)
- [MetaMask](https://metamask.io/) browser extension

## Setup & Installation

### 1. Clone the repository

```bash
git clone <your-repo-url>
cd UnityLedger
```

### 2. Install Node dependencies

```bash
npm install
```

### 3. Install Truffle globally

```bash
npm install -g truffle
```

### 4. Set up Ganache

1. Download and open [Ganache](https://trufflesuite.com/ganache/).
2. Create a new workspace named **development**.
3. In the **Truffle Projects** section, click **Add Project** and select `truffle-config.js` from this repo.
4. Start the workspace. Ganache will run a local blockchain at `http://localhost:7545`.

### 5. Configure MetaMask

1. Install the [MetaMask](https://metamask.io/download/) browser extension.
2. Add a custom network with these settings:

   | Field | Value |
   |-------|-------|
   | Network Name | Localhost 7545 |
   | RPC URL | http://localhost:7545 |
   | Chain ID | 1337 |
   | Currency Symbol | ETH |

3. Import accounts from Ganache into MetaMask using the private keys shown in Ganache's **Accounts** tab.

   > **Important:** The **first account** (index 0) in Ganache is the one that deploys the contract and becomes the **Admin**. Import this account first if you want admin access.

### 6. Compile and deploy the smart contract

Open a terminal in the project root:

```bash
truffle console
```

Inside the Truffle console:

```
compile
```

Then exit the console (`Ctrl+C` or `.exit`) and migrate the contract to your local blockchain:

```bash
truffle migrate
```

### 7. Bundle the frontend JavaScript

```bash
browserify ./src/js/app.js -o ./src/dist/app.bundle.js
```

### 8. Start the web server

```bash
node index.js
```

The app is now running at **http://localhost:8080**.

## Using the Application

### Connecting your wallet

1. Open **http://localhost:8080** in your browser.
2. MetaMask will prompt you to connect — approve it.
3. Your role is detected automatically:
   - If your address matches the contract deployer → **Admin panel** is shown.
   - Any other address → **Voter panel** is shown.

Your current address and role are displayed at the top of the page.

### As an Admin

Navigate to **http://localhost:8080/admin.html**. You will see the admin controls only if your connected wallet is the contract deployer.

- **Add Candidate** — Enter a candidate's name and party, then click *Add Candidate*.
- **Define Voting Dates** — Set the start and end dates for the voting period, then click *Define Dates*. This can only be done once.

### As a Voter

1. Select a candidate from the list on the main page.
2. Click **Vote**.
3. MetaMask will ask you to confirm the transaction — approve it.
4. Once confirmed, your vote is recorded on-chain. Each wallet address can only vote once.

---

## Switching Between Admin and Voter

To switch roles, change the active account in MetaMask:

- Select the **Ganache account 0** (the deployer) → Admin access.
- Select **any other Ganache account** → Voter access.

The page refreshes its role detection on each load.

## Troubleshooting

**MetaMask shows wrong network**
Make sure you have added and selected the *Localhost 7545* network in MetaMask. The Chain ID must be `1337`.

**"Only admin can perform this action" error**
Your connected wallet is not the contract deployer. Switch to Ganache account 0 in MetaMask.

**Candidates or dates not loading**
Ensure `truffle migrate` has been run *after* Ganache is running, and that the `build/contracts/Voting.json` file exists. If it is missing, run `truffle compile` then `truffle migrate`.

**Browserify command not found**
Install it globally: `npm install -g browserify`

**Vote button stays disabled**
Your wallet has already voted. Each address may only vote once. Switch to a different Ganache account to test voting again.
